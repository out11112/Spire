# Spire 终端扩展

LinkChatCLI 的可选卡牌游戏界面。当前包版本为 **0.8.2**（见 [package.json](package.json)），扩展 API 为 **4**，要求 Node.js 24。游戏服务由 [LinkChat Spire 后端扩展](https://github.com/out11112/LinkChat/tree/main/extensions/spire)提供；客户端扩展只负责界面，房间存档保存在服务器。

客户端和后端当前使用游戏协议 **8**。后端规则标识为 `spire-tui-4`，内容标识为 `0.1.0-alpha.2.dev17`。不兼容的协议会明确报错，不能用旧客户端继续提交游戏动作。建议同步更新 LinkChatCLI、此扩展和后端扩展；当前配套 LinkChatCLI 版本为 0.13.2（扩展接口 4）。

## 安装与进入

在本地客户端执行：

```sh
linkchat extension install spire
linkchat extension update spire
linkchat extension list
```

安装本地包可用 `linkchat extension install spire --from /绝对路径/扩展包.tgz`。卸载使用 `linkchat extension remove spire`，不会删除服务器存档。安装或更新后重新启动 `linkchat`，进入频道输入 `/spire`。SSH 用户由网关管理员安装扩展；当前频道需要后端已经启用游戏。完整安装入口见 [LinkChatCLI README](../../README.md)。

## 大厅与资料库

主界面包含单人模式、多人联机、资料库、设置、退出。单人先选角色与 A0–A10 进阶；已有存档可继续，开始新局需要确认替换，后端按存档版本原子替换。多人房主创建前选角色与进阶，加入者选择自己的角色；等待大厅可更换自己的角色并取消自己的准备，开始后不能更改配置。多人至少需要两名不同玩家在线才能准备、开始或继续；不足时显示等待队友，创建房间不等于单人开局。

多人存档只能由房主先进入恢复，其他玩家随后才能搜索到房间。房主离开后房间暂停并从其他人的列表隐藏；已开始的房间仅原成员可继续。多人房间页直接输入即可搜索房主或成员，Ctrl+R 刷新。

资料库数据随扩展安装到本地，首次按分类读取后缓存在内存；进入、搜索、详情、卡牌升级与怪物 A0–A10 参考数值均无需联网。页面显示本地资料修订号，更新扩展即可更新资料。存档、房间、开局配置和战斗规则仍由服务器提供。

资料库外层以普通列表选择卡牌、怪物、遗物、药水或角色，方向键选择、Enter 进入。内部顶部只显示小类，不显示“全部”，默认进入第一个小类；以 Tab / Shift+Tab 或点击标签切换角色、卡池或遭遇类型等小类；Esc 返回外层大类列表。支持直接输入或粘贴即时模糊搜索（与 /members 相同），退格删除、Ctrl+U 清空、左右翻页、Enter 详情。详情支持 U 升级卡牌、左右查看怪物 A0–A10 基础值、上下键选择关联卡牌或遗物并 Enter 查看，PgUp/PgDn 滚动文字。怪物数值为单人基础，具体出招受战斗状态和同伴影响。110 列及以上左右分栏预览，较窄终端在列表下方预览。

战斗中牌堆按钮写作 `[A 抽牌堆 6]`，牌组写作 `[D 牌组 11]`；抽牌堆、弃牌堆、消耗牌堆张数变化时，数字短暂以该牌堆的颜色高亮，按钮宽度不变；任意按键或点击立即结束。设置按一行一个列出快捷键，不包含自定义键位。游戏菜单的退出返回主界面；主界面按 Esc、选择退出或任意页面 Ctrl+C/D 返回聊天频道。开局大厅需要配套后端，旧后端会显示明确提示；本地资料库可独立浏览。

## 游戏与操作

支持单人及 2–4 人合作，队友不必在同一频道。玩家创建或加入房间、选角色、准备后开始；断线或退出房间会暂停游戏，玩家重新连接并准备后继续。游戏包括五位角色、三幕路线、A0–A10 进阶、战斗、路线投票、奖励、商店、事件、休息和宝箱。已有房间的难度在创建后固定。

| 操作 | 用途 |
| --- | --- |
| 方向键、Enter、鼠标单击 | 移动焦点并确认当前动作或目标 |
| Esc | 先关闭选目标、详情或地图；失败后直接返回主界面；其他游戏阶段打开菜单，可返回主界面并保留存档 |
| Ctrl+C / Ctrl+D | 退出 Spire，返回聊天 |
| `D`、`A`、`S`、`X` | 查看牌组、抽牌堆、弃牌堆、消耗牌堆；再次按相同键或点击对应按钮返回 |
| `M` | 查看或关闭地图 |
| `E`、`V` | 结束回合、查看完整战斗日志 |
| `T` | 打开房间聊天输入框 |
| `G` | 占卜球体中切换工具；方向键移动、空格揭开 |
| `I` | 选中或悬停角色、敌人后查看状态详情；商店查看商品详情 |
| `?` | 查看全部快捷键和当前项目说明；方向键浏览，再按 `?` 或 Esc 返回 |

手牌、敌人和队友可用键盘或鼠标选择；需要指定目标的牌或药水会先进入选目标状态，确认后才提交。地图按房间位置选择路线并投票；商店、奖励和宝箱按画面中的操作提示完成。界面会随终端尺寸切换布局，地图最低需要 40 列、12 行，普通游戏画面建议至少 40 列、20 行。鼠标操作取决于终端支持；需要复制终端文本时可按住 Shift 拖拽。

战斗日志由后端按场次保存，界面用 `V` 分页查看；私人抽牌信息只对本人可见。请求结果不确定时，先等待状态同步或按画面提示重试，避免创建新的重复动作。

## 房间聊天

进入房间后按 `T`，输入文字并按 Enter 发送，Esc 取消。聊天只发送给当前房间玩家，不进入频道聊天；最多显示最近 8 条，每条显示 60 秒。每条最多 200 个字符，重连后不回放历史。后端快照必须声明 `features.roomChat` 才显示入口；具体限流和协议见 [后端 API 文档](https://github.com/out11112/LinkChat/blob/main/extensions/spire/API.md#房间即时聊天)。

## SL

进入战斗、事件或火堆后，按 T 输入 `/sl`。单人立即恢复该场景初始状态；多人只有房主输入 `/sl` 可立即恢复当前场景，其他成员不能触发，无需投票。SL 同时恢复随机状态，相同操作得到相同结果。

存档点和请求绑定当前节点和阶段：换节点、事件内进入战斗、暂停或成功 SL 后旧请求失效。事件和其中的战斗保留各自初始状态。结算离开场景后不能回退；更新前已经处于场景中的旧存档，要进入下一个支持场景才有初始存档点。

## 开发

从仓库根目录运行 `npm ci`、`npm run check` 和 `npm run package:extensions`。扩展入口为 [index.js](index.js)，大厅与资料库位于 [lobby.js](lobby.js)，房间聊天界面位于 [room-chat.js](room-chat.js)；契约测试位于仓库 `tests/spire-*.test.mjs`。原作程序、美术、音频和存档不包含在此包中。

单人存档在“继续存档”下方提供红色“放弃当前存档”；多人房主在游戏菜单中可直接放弃，无需投票。恢复存档在原成员连接到齐后自动继续，新建多人房间仍需准备。

局内卡牌升级预览随游戏状态同步，打开预览及切换升级卡牌无需额外网络请求，保留当前实例的动态费用和效果。

## 低延迟动作

要求游戏协议 8 和 `linkchat-game-v8` 子协议，固定使用 WS 动作确认，最多 8 个待确认意图；不提供旧版本或 HTTP 动作回退。出牌等待确认时保持卡牌名称和布局稳定，游戏规则仍由服务器结算。超时或断线恢复后自动通过 WebSocket SYNC 核对原动作回执；R 可提前核对。核对期间冻结新动作，不会自动补执行未提交的队列尾部。后端必须声明 features.actionSync=true。服务端批量接口及重试语义见 LinkChat 仓库 `extensions/spire/API.md`。

设置 `LINKCHAT_SPIRE_TIMING_FILE` 可记录动作确认耗时 JSONL；部署端需启用 HTTP gzip 和 WebSocket permessage-deflate。

协议 7 删除逐牌 HTTP 升级预览，统一使用快照中的 `upgradePreviews`；HTTP 单动作默认不向操作者重复广播。CLI 与扩展 API 3 必须配套更新。

## 商店（0.6.2）

商店沿用资料库的分类标签、固定列列表和选中预览。Tab / Shift+Tab 或点击标签切换全部、卡牌、遗物、药水、删牌，各分类记住选中商品；金币、药水容量和离开入口固定可见。110 列及以上左右分栏，较窄终端上下排列，40×20 仍保留效果摘要及列表价格，短描述会让出更多商品行。

↑↓ 或鼠标悬停预览商品；单击卡牌、遗物或药水商品行直接购买，也可按 Enter 提交。连续点击在等待回执时只提交一次；价格或库存变化后需按刷新后的列表重新点击。I 查看完整效果，U 预览升级，D 查看牌组，T 房间聊天，Esc 打开游戏菜单。E 或点击选择离开商店，按钮变为 `[点击/Enter 确认]`，再次点击或按 Enter 离开。价格和效果来自当前服务器状态。购买后按商品 ID 保持位置，已售商品移除后顺延选择；药水满栏进入药水管理，单击删牌服务打开选牌界面，确认名称和费用后才扣费移除。

0.6.4：离开按钮默认显示 `[E 离开商店]`，按 E 或点击只选中，选中后显示 `[Enter 确认]`，按 Enter 才提交离开。

0.6.5：移除详情底部重复售价、余额、差额及购买按钮，只保留位置计数和上下选择；空白提示行不占高度，窄屏按实际描述长度增加商品列表空间。
